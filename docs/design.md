# Дизайн Ritm

Пользователь утвердил фиолетовую палитру и разрешил реализацию 13 октября 2026 года.

Эталон: `design/approved-preview.html` — компьютер, телефон, формы и состояния. Он хранится как архив решения; приложение строится обычными компонентами из этих макетов.

## Палитра

| Роль                 | Светлая тема | Тёмная тема |
| -------------------- | ------------ | ----------- |
| Фон                  | `#F7F5FB`    | `#12101B`   |
| Текст                | `#29223B`    | `#F1EBFB`   |
| Второстепенный текст | `#756B80`    | `#AAA0BA`   |
| Главный акцент       | `#7651BC`    | `#B99CEB`   |
| Мягкий акцент        | `#F0EAF9`    | `#30253E`   |
| Граница              | `#E8E2F0`    | `#352B45`   |

Сохранять крупные заголовки, три карточки обзора, светящуюся сферу ИИ, тонкие границы и графитовую навигацию. Анимации подчёркивают действия и учитывают `prefers-reduced-motion`.

## Работа с ветками

`codex/ritm-design` фиксирует утверждённое решение. `codex/ritm-app` содержит реализацию. Последующие изменения дизайна делаются отдельными ветками от актуального приложения и объединяются после проверки. Палитру и темы изменять в визуальных токенах; прикладные данные и действия остаются независимыми.
