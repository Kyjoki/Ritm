# Система обратной связи — 28 октября 2026

Каждое действие пользователя получает видимый отклик, без отдельной разметки в экранах.

## Где живёт

- `src/components/InteractionLayer.tsx` — один слой на документ (подключён в `main.tsx`).
- `src/lib/action-feedback.ts` — чистая машина состояний кнопки, тесты в `tests/action-feedback.test.ts`.
- `src/styles/interaction.css` — общие токены движения и состояния; подключается последним.
- Существующие примитивы `Motion.tsx` (страницы, FLIP-списки, индикаторы, числа) не изменены.

## Что видит пользователь

| Действие                                     | Отклик                                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Нажатие любой кнопки, вкладки, переключателя | «Удар» — кольцо расходится от элемента (фирменный пульс Ritm), кнопка проседает и возвращается на пружине    |
| Асинхронная кнопка (`disabled={busy}`)       | Волна загрузки → вспышка с галочкой или красная рамка с покачиванием при ошибке                              |
| Отметка задачи, привычки, переключатель      | Пружинная галочка с прорисовкой и усиленный пульс при включении                                              |
| Поле ввода                                   | Подсветка при наведении, мягкое кольцо фокуса, заполненное состояние, красная рамка и покачивание при ошибке |
| Ошибки и подсказки                           | Появляются со смещением, а не вспышкой                                                                       |
| Диалоги, уведомления                         | Открываются на пружине, закрываются коротким исчезновением                                                   |
| Индикаторы навигации и сегментов             | Двигаются на той же пружине                                                                                  |

## Как слой понимает «загрузку»

Кнопка становится «загружающейся», только если её выключили в течение 600 мс после нажатия и есть признак работы: вместе с ней выключились поля той же формы или диалога, сменилась подпись («Сохраняем…») или внутри появился спиннер. Иначе это обычная смена состояния (например, «следующий период» на текущей неделе). Конец работы — кнопка или её соседи снова включены. Если между нажатием и концом появилась ошибка (`role="alert"`, `.error-note`, `.toast-error`, `aria-invalid`), исход — «ошибка». Предохранитель снимает загрузку через 15 с.

Отключить отклик для конкретной кнопки пока нельзя; если понадобится, добавьте проверку атрибута `data-no-feedback` в `onClick` слоя.

## Ритм

Нажатие 110 мс · смена состояния 180 мс · перемещение 260 мс · поверхности 400 мс. Всё, что перемещается, идёт по пружине (`--ease-spring`), цвет — по ease-out. Ни одна анимация не задерживает само действие.

## Уменьшенное движение

При `prefers-reduced-motion` перемещения, волны и пульсы отключаются, состояния остаются видимыми (галочка успеха, красная рамка ошибки, мгновенная смена).
