# Локальный motion preview

Используется текущая рабочая копия и изолированные локальные данные из `scripts/preview-visual.mjs`; production, Google, Telegram и внешние модели для демонстрации не подключаются.

Запуск с Node 24: `npm run preview:visual`.

- Интерактивный маршрут: http://127.0.0.1:5176/preview/motion.html
- Приложение без рамки: http://127.0.0.1:5176/?design-preview=1#day
- Мобильная рамка: http://127.0.0.1:5176/__dev/mobile-preview (только Vite dev server).

Порты можно задать переменными `RITM_PREVIEW_PORT` и `RITM_PREVIEW_API_PORT` (по умолчанию 5176 и 3002). На одном порту не запускайте две разные рабочие копии. Рамка поддерживает ширины 320, 360, 375, 390, 393 и 430 px, поворот экрана и HMR. Это браузерная проверка адаптивности, не проверка Safari или установленной iOS PWA.

## Сценарий

1. «Мой день» → «Повторить первое появление»: заголовок → показатели → рабочие блоки. Линия прорисовывается по пути, затем появляется заливка; кольцо и число достигают итоговых значений.
2. «Графики»: столбцы финансов растут последовательно, кольцо заполняется по дуге. Переключение видов сохраняет карточки и переводит существующие счётчики к новым суммам.
3. «Выполнение»: отметьте локальную задачу. Галочка, счётчик и кольцо обновляются, соседние строки перемещаются. «Отменить» возвращает исходный результат.
4. «Период»: неделя/месяц и стрелки в привычках. Карточка аналитики не исчезает; существующие столбцы переходят к новым высотам. Отметка привычки меняет дугу, числа, streak и heatmap.
5. «Переходы»: введите черновик быстрого добавления, перейдите в другой раздел через навигацию Ritm и вернитесь. Черновик сохраняется. Индикатор перемещается между пунктами.
6. «Диалог»: «Новая привычка», затем крестик или Escape. Нативный dialog появляется из центра и закрывается вместе с backdrop. Для длинного содержимого остаётся внутренняя прокрутка.

Переключатель ширины показывает настоящий интерфейс в iframe: desktop, 360, 390 и 430 px. Это интерактивная демонстрация, не видеозапись и не эмуляция настоящего iPhone.

## Реализация

- `MotionPage`: поставленная последовательность с задержками до 220 мс; более короткий возврат в раздел. Примитив размещён внутри React Activity, без ключей, сбрасывающих страницу.
- `MotionNumber`, `MotionBar`, `MotionRing`, `MotionArc`, `MotionLine`: первое появление около 920 мс, обновление 520 мс. На телефоне длительности короче на 25%. Покадровые обновления изолированы внутри показателя.
- `MotionList`: появление, визуальное удаление и FLIP-перестройка обычных списков. Календарь не входит в механизм.
- `MotionControls`: перемещение общего индикатора, плавное раскрытие native details. Масштаб приложения учитывается при измерении координат.
- `MotionPresence`: завершение анимации уведомления перед удалением. Диалоги используют существующий native close/focus lifecycle.
- Скрытые Activity и невидимый документ останавливают декоративные CSS-циклы. RAF прерывается при отключении эффектов Activity. Старые CSS-анимации графиков и страниц отключены в новом слое, чтобы избежать повторных запусков.
- `prefers-reduced-motion`: конечные числа сразу, без перемещения и декоративных циклов. История сообщений ИИ не переигрывается при возврате.

## Проверено

- TypeScript, сборка и 247 тестов, включая четыре теста интерполяции: точные денежные значения, обратный переход, изменение длины ряда, отсутствие превышения конечного значения.
- В браузере: начальные и промежуточные кадры графиков, выполнение задачи и привычки, неделя/месяц, добавление/удаление временной локальной задачи, закрытие уведомления, переключение темы.
- Mobile в iframe: 360/390/430 px, нижняя навигация, сохранение черновика через React Activity, диалог и Escape. Настоящие touch-жесты, iOS-клавиатура и системный переключатель reduced motion на физическом телефоне не проверены.
- Ответ внешней модели в изолированном демо не отправлялся. Сохранена существующая логика свежих сообщений, дополнительно очищается временный признак анимации после повторного подключения Activity.
- В сборке остаётся существующее предупреждение Vite о размере основного JS chunk более 500 kB.

## Проверка перед выпуском

- Выполненная привычка в «Моём дне» сохраняет контрастную заливку при наведении: светлая hover-заливка применяется только к незавершённым отметкам.
- Прорисовка галочки учитывает SVG `path` текущей версии Lucide, а не только `polyline`.
- Повторно проверены наведение в обеих темах, отмена/повторная отметка и счётчик, мобильная ширина 390 px. Полный набор: 247 тестов, сборка, Prettier и npm audit (0 уязвимостей).
