# Проверки Ritm

Дата: 13 октября 2026 года. Runtime: Node.js 24.19.0.

## Проверяемый сценарий

Пользователь открывает Ritm, входит в личный аккаунт, создаёт задачи, видит расписание и Google-события, сохраняет настройки и общается с OpenAI. Клиент вызывает Express API; локально данные сохраняются в SQLite, для Vercel подготовлен PostgreSQL. Подтверждённые предложения ИИ обновляют задачи транзакцией после проверки занятости Google.

У установленной версии режим соответствует `verify-full`; наблюдавшиеся ответы API успешны. Оповещения и постоянный мониторинг не настроены.

Автопубликация каждого push в main разрешена владельцем. После подключения GitHub Login Connection и доступа приложения Vercel Git connect завершён. API проекта подтвердил `Kyjoki/Ritm`, `productionBranch=main`, включённые Git deployment и auto-assignment. Первый автоматический выпуск проверяется новым commit документации с автором Kyjoki и Codex как соавтором; пока подтверждена связь, результат Git deployment фиксируется отдельно.

Публичный экран входа дополнительно открыт во встроенном браузере: форма загрузилась, логин и пароль подписаны, кнопка входа недоступна при пустых полях, светлая фиолетовая тема отрисовалась. Это проверка экрана входа, остальные разделы и мобильные сценарии в браузере пока не подтверждены.

## Ручная проверка после запуска

1. Открыть четыре раздела, переключить обе темы; проверить 320/375/768/1920 px.
2. Создать задачу, изменить время, выполнить повторение за одну дату, удалить и отменить удаление.
3. Проверить свободный интервал, переключатели календаря, «Сегодня» и переход периода.
4. Сохранить настройки; проверить ошибки, фокус полей и работу клавиатуры в формах.
5. Настроить свой OpenAI, отправить запрос, выбрать предложение и подтвердить его; проверить отмену.
6. Открыть один защищённый адрес с компьютера и телефона; после обновления проверить общие данные.

Дизайн проверен по исходникам и утверждённому референсу. Эти проверки не подтверждают визуальное совпадение работающего приложения в браузере и не заменяют проверку перед публичной публикацией.
