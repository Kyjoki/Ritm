# Команда

Координатор собирает выводы специалистов и ведёт проект в этом чате. Агенты подключаются этапами; одновременно работают до трёх специалистов помимо координатора.

| Роль | Ответственность |
| --- | --- |
| Frontend-разработчик 1 | Структура интерфейса и компоненты |
| Frontend-разработчик 2 | Адаптивность, доступность, интерфейсные контракты |
| Backend-разработчик 1 | Данные и прикладная логика |
| Backend-разработчик 2 | Серверная интеграция OpenAI и API |
| Архитектор ИИ-агента | Границы системы, инструменты, хранение и интеграции |
| Дизайн-агент 1 | Пользовательские сценарии и структура экранов |
| Дизайн-агент 2 | Визуальная система и мобильный интерфейс |
| Оценщик продукта | Проверка пользы идей, приоритетов и понятности сценариев |
| Специалист по безопасности 1 | Защита данных, секретов и кода |
| Специалист по безопасности 2 | Авторизация, внешние интеграции и злоупотребления |
| QA-специалист | Сквозные сценарии и проверка качества |

Перед реализацией дизайн-агенты работают с пользовательским дизайн-промптом. Архитектор и разработчики после этого готовят технический план; безопасность и QA проверяют его и реализацию.
