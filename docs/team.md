# Команда

Координатор ведёт проект и общение с пользователем в этом чате. Lead-агент распределяет этапы, собирает выводы специалистов и передаёт спорные решения координатору. Агенты подключаются этапами; одновременно работают до трёх специалистов помимо координатора.

| Роль | Ответственность |
| --- | --- |
| Lead-агент | Координация специалистов, зависимости, противоречия и единый список решений |
| Frontend-разработчик 1 | Структура интерфейса и компоненты |
| Frontend-разработчик 2 | Адаптивность, доступность, интерфейсные контракты |
| Backend-разработчик 1 | Данные и прикладная логика |
| Backend-разработчик 2 | Серверная интеграция OpenAI и API |
| Архитектор ИИ-агента | Границы системы, инструменты, хранение и интеграции |
| Дизайн-агент 1 | Пользовательские сценарии и структура экранов |
| Дизайн-агент 2 | Визуальная система и мобильный интерфейс |
| Оценщик продукта | Проверка пользы идей, приоритетов и понятности сценариев |
| Оценщик качества ИИ | Проверка полезности, точности и уместности планов, шагов и отчётов |
| Специалист по Google Calendar | Контракт интеграции, разрешения и синхронизация; пользователь ведёт её реализацию |
| Специалист по доступности | Клавиатура, экранные дикторы, контраст и мобильные сценарии |
| Инженер эксплуатации | Деплой, мониторинг, восстановление, расходы API и конфигурация |
| Специалист по безопасности 1 | Защита данных, секретов и кода |
| Специалист по безопасности 2 | Авторизация, внешние интеграции и злоупотребления |
| QA-специалист | Сквозные сценарии и проверка качества |

Перед реализацией lead-агент разбирает пользовательский дизайн-промпт с дизайнерами и оценщиком продукта. Архитектор и разработчики после согласования дизайна готовят технический план; оценщик качества ИИ, специалист по Google Calendar, доступности и эксплуатации добавляют требования своей области. Безопасность и QA проверяют план и реализацию. Продуктовые вопросы пользователю передаёт координатор.
