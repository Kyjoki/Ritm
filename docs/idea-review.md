# Разбор идей

В «ИИ-помощник» переключатель «Разбор идей» отправляет полный текст идеи на отдельную оценку четырём ролям:

- **Польза:** потребность, аудитория, существующие способы решения.
- **Реализация:** осуществимость, зависимости, минимальная проверка.
- **Ресурсы:** усилия, расходы, поддержка, альтернативная стоимость.
- **Риски:** слабые допущения, последствия и условия неуспеха.

Каждый эксперт получает только текущее сообщение пользователя и свои инструкции. Другие оценки, история диалога, календарь и задачи не передаются. Пятый запрос получает исходную идею и четыре проверенных ответа; формирует общий вывод, согласия, разногласия, вопросы и следующие шаги. Числовой рейтинг не используется.

Используется одна модель, выбранная в настройках OpenAI. Отдельный контекст не гарантирует разнообразия моделей или отсутствия общих ошибок. Доступа к интернету нет: неизвестные факты, спрос, стоимость и сроки должны быть отмечены как допущения и проверены человеком. Каждый новый разбор оценивает новое сообщение целиком.

## API и хранение

`POST /api/chat` принимает необязательное поле `mode: "idea_review"`. Обычный режим остаётся совместимым с прежними запросами. Режим включён в fingerprint только для разбора идей; повтор того же requestId возвращает сохранённый результат, а другой режим с тем же ID отклоняется. История содержит `ChatMessage.ideaReview` версии1. Используется прежнее серверное хранилище JSON; SQL-миграций нет.

Отчёт проходит строгую проверку структуры, размеров и четырёх разных ролей перед сохранением. Предложения изменения задач и шаги планировщика пусты. Оценки показываются раскрывающимися карточками, общий вывод — первым. Копирование включает весь отчёт.

## Ограничения выполнения

- Вход: до 6000 символов, текст не обрезается незаметно.
- Четыре вызова экспертов и один итоговый вызов, без автоматических повторов.
- Не более двух одновременных запросов к модели; весь разбор занимает оба существующих общих AI-слота владельца.
- Общий предел100 секунд, отдельного вызова45 секунд; общий durable lease180 секунд.
- До1400 выходных токенов на эксперта и1800 на итог; максимум7400 выходных токенов за разбор.
- Не более шести новых разборов в минуту поверх общей квоты чата. Ограничение Ritm возвращает `Retry-After` и время ожидания; кнопка повторной отправки показывает обратный отсчёт. Ограничения OpenAI отображаются отдельно.
- Отмена и сбой ждут завершения параллельных вызовов до освобождения слотов.
- При сбое одного эксперта неполный отчёт и выдуманный итог не сохраняются. Явный повтор может снова вызвать модель; прежние вызовы могут быть тарифицированы OpenAI.

API-ключ остаётся на сервере. Транспорт разрешает только POST `https://api.openai.com/v1/responses`, без перенаправлений и с пределом размера ответа. `store:false`, инструментов и действий нет. Ввод или ответ с API-ключом отклоняется; исходные ошибки провайдера, личные идеи и заголовки авторизации не выводятся в лог.

## Проверки

`tests/idea-review.test.ts` проверяет отдельные контексты, последовательность итогового вызова, отмену и завершение соседнего запроса, сроки, границы, секреты и ошибки. Подменённый HTTP-транспорт дополнительно проверяет настоящий установленный AI SDK и пять Responses-запросов, строгий формат, модель, лимиты и `store:false`.

`tests/idea-review-api.test.ts` проверяет HTTP-поток, сохранение и повторное чтение, отсутствие обращений к Calendar, отсутствие действий, повтор без дублей, проверку режима, частичные ответы и общие слоты выполнения. Тесты не вызывают платный API.
