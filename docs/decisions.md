# Открытые решения

| Вопрос                                 | Статус                                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Визуальный стиль и макеты              | Утверждены 13.10.2026: фиолетовые светлая/тёмная темы, графитовая навигация, орб ИИ, короткие анимации |
| Состав первого релиза                  | Задачи, календарь, ИИ-помощник, настройки; адаптивный интерфейс                                        |
| Синхронизация задач между устройствами | Общая SQLite одного сервера; другое устройство видит изменения после обновления страницы               |
| Серверная база файлов и заметок        | Отложена по решению пользователя                                                                       |
| Google Calendar                        | Пользователь планирует интеграцию                                                                      |

| Публикация приложения                  | Сначала полноценная реализация в указанном GitHub-репозитории и локальная проверка                     |

Утверждённый дизайн сохранён в ветке `codex/ritm-design`. Реализация идёт в `codex/ritm-app`. В будущем дизайн меняется отдельными ветками от актуальной основной ветки с последующим объединением. Темы и компоненты находятся в исходниках приложения, а не в постоянно расходящемся отдельном форке.
