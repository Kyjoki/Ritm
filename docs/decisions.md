# Открытые решения

| Вопрос                                 | Статус                                                                                                                |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Визуальный стиль и макеты              | Утверждены 13.10.2026: фиолетовые светлая/тёмная темы, графитовая навигация, орб ИИ, короткие анимации                |
| Состав первого релиза                  | Задачи, календарь, ИИ-помощник, настройки; адаптивный интерфейс                                                       |
| Синхронизация задач между устройствами | Локально SQLite, для Vercel PostgreSQL; обновление после загрузки страницы                                            |
| Серверная база файлов и заметок        | Отложена по решению пользователя                                                                                      |
| Google Calendar                        | Единый календарь primary: создание, изменение и удаление в Ritm сохраняются в Google; чтение автоматически каждые 30с |
| OpenAI                                 | Серверный AI SDK7 ToolLoopAgent, Responses и structured output; ключ в окружении или AES-GCM хранилище                |
| Вход                                   | Один аккаунт владельца: логин + пароль, без регистрации                                                               |
| Публикация приложения                  | Опубликовано на ritm-eta-hazel.vercel.app; PR #1 объединён в main, Neon production подключена                         |
| Автопубликация push в main             | Разрешена и проверена: commit4329073 автоматически опубликован Vercel, основной домен назначен                        |
| Вид календаря                          | Воскресенье первым, AM/PM, 48px/час; окно 9 AM–9 PM и полный день 0–24 через прокрутку; текст сверху, без G           |
| Цвета и редактирование Google          | Палитра 24 оттенка, мягкие карточки; native labels для новых цветов после явного OAuth opt-in; серия не меняется      |
| Старые записи календаря Ritm           | Незавершённые записи с датой безопасно переносятся в Google; без даты остаются локальными; выбора Ritm/Google нет     |

Утверждённый дизайн сохранён в ветке `codex/ritm-design`. Реализация из `codex/ritm-app` объединена в `main`. В будущем дизайн меняется отдельными ветками от актуальной основной ветки с последующим объединением. Темы и компоненты находятся в исходниках приложения, а не в постоянно расходящемся отдельном форке.
