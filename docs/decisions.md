# Открытые решения

| Вопрос | Статус |
| --- | --- |
| Визуальный стиль и макеты | Ждём дизайн-промпт пользователя |
| Состав первого релиза | Определим после дизайна |
| Синхронизация задач между устройствами | Не решено |
| Серверная база файлов и заметок | Отложена по решению пользователя |
| Google Calendar | Пользователь планирует интеграцию |
| OpenAI | Провайдер выбран; секрет должен храниться вне клиентского кода |
| Публикация приложения | После согласования дизайна и реализации |
