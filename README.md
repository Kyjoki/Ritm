# Ritm

Ritm — будущий веб-ассистент для работы, учёбы и личных дел. Проект находится на этапе проектирования: сначала утверждаем дизайн и основные сценарии, затем начинаем реализацию.

## Планируемые возможности

- задачи и план дня;
- календарь с будущей интеграцией Google Calendar;
- помощник на базе OpenAI для разбивки задач и подготовки отчётов;
- использование на компьютере и телефоне.

Заметки и файлы входят в общее видение продукта. Серверную базу для них пока не добавляем. Состав первого релиза уточним после дизайн-промпта.
