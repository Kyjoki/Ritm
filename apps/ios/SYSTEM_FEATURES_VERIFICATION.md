## Календарные уведомления и формат build 4

Владелец подтвердил доставку календарного уведомления в build 3 скриншотом экрана блокировки.
Случай с прежним Test объяснялся отдельным выключенным оповещением задач/календаря; разрешение
и переключатель отдыха его не включают. После включения и сохранения общего переключателя
новое календарное напоминание пришло.

По следующему запросу владельца формат уведомлений о событиях и задачах изменён:
исходное название в title, реальный диапазон времени в body вместо заголовка «Ritm · Через
30 минут». Пример: **Test** / `22:45–23:45`. Слово Test не зашито в приложение. Часовой пояс
берётся из настроек аккаунта; часы всегда 24-часовые, даты локализуются для RU/EN. Ночные,
многодневные и пересекающие границу года события явно содержат даты; смена UTC offset
показывается у обеих границ. При неизвестной/невалидной длительности задачи указан только
достоверный момент начала. Напоминания отдыха, покупок и утреннего плана не переработаны.

конвертация часового пояса, начало на следующий день относительно момента уведомления,
ночь, DST и длительности. Автоматический Time Sensitive не добавлялся.

## Что ещё требует iPhone

Отдельно ещё не проверены на устройстве: новый формат текста build 4,
новая реальная покупка после импорта, обновление виджета после изменения привычки и очистка
после выхода. Для них есть portable-тесты планирования/reconciliation/контекста, которые не
заменяют реальную доставку iOS. Завершение всего журнала также сохраняет in-app review;
реальные подходы владельца ради проверки не добавлялись и не удалялись.

Для сборок WSL использовалась Linux filesystem: `/var/tmp`, ограничение CPU affinity до
двух ядер и постоянный `RITM_ARTIFACT_ROOT`. На `/mnt/c` наблюдался сбой dependency scanner
Swift; каталог сборки в `/tmp` после завершения процессов оказался недоступен. Итоговые
артефакты сохранены в постоянной папке Windows; повторная сборка из `/var/tmp` пройдена.
В неизменённых native views остаются предупреждения Swift 6.4 об actor isolation;
компиляция завершается успешно.
