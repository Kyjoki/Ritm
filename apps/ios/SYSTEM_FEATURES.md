# Системные поверхности Ritm для iPhone

Изолированная ветка: `chatgpt/ios-notifications-widgets-live-activities`.
Основные экраны и их утверждённое оформление сохраняются. Новый UI находится в WidgetKit
extension, а не в веб-приложении. Vercel deployment этой ветки отключён в `vercel.json`.

## Live Activity тренировки

- Один активный журнал и один ActivityKit Attributes type из `RitmSystem` для app и extension.
- Абсолютный системный таймер отдыха: не требует таймера React, открытого сайта или
  ежесекундного выполнения кода приложения.
- Текущее упражнение, его номер, подход, рабочий вес/повторы с существующей настройкой
  скрытия весов. Сохраняются отдельные переключатели Activity и уведомления об отдыхе.
- После последнего подхода выбирается первое незавершённое упражнение. Отдых использует
  длительность конкретного упражнения, как кнопка выполнения внутри Ritm.
- Нажатие несёт ID тренировки, ID подхода и непрозрачную ревизию. Повторный/устаревший
  запрос не отмечает следующий подход и не добавляет отдых повторно. Запись журнала и
  запросы ActivityKit/уведомлений завершаются перед возвратом фонового действия.
- Завершение всего журнала открывает существующий экран: запись тренировки не сохраняется
  незаметно из старой карточки. Отключение Activity и отмена тренировки убирают карточку.
- При штатной повторной загрузке того же журнала ревизия сохраняется. При расхождении
  сохранённых данных старое действие отклоняется.

Прямые фоновые кнопки `LiveActivityIntent` включены по умолчанию (`RITM_INTERACTIVE=1`);
metadata создаётся из результатов реальной компиляции. Владелец подтвердил работу на
iPhone 13. Режим ссылок `RITM_INTERACTIVE=0` оставлен только для диагностики. При пустом
весе/повторах карточка предлагает ввести значение и открывает соответствующее поле в Ritm,
сохраняя подход невыполненным. На iPhone 13 основная поверхность — экран блокировки;
для моделей с Dynamic Island также есть compact/minimal/expanded представления.

## Виджет «Мой день и привычки»

Small и medium, без отдельного виджета тренировок. Показывает подтверждённые задачи,
запланированные на день привычки и ближайшее загруженное событие. Расчёт привычек использует
`HabitSchedule`, включая историю расписания, архив и часовой пояс. Неизвестный статус Google
Task не выдаётся за выполненный или невыполненный.

App — единственный писатель небольшого JSON-снимка в App Group. Виджет не получает
пароли, сессию API, email, переписку, описание задач или финансовую историю. Общий Keychain
для сессии не используется. Снимок ограничен по размеру и количеству строк, записывается
атомарно и истекает в полночь пользователя либо при истечении сессии. Повреждённый снимок,
отсутствие App Group или устаревшая дата дают понятное предложение открыть Ritm.

Timeline меняет ближайшее событие по уже известным границам времени. Серверные изменения
и новый день требуют синхронизации приложения; WidgetKit сам определяет время перерисовки.
Нажатия по делам и привычкам открывают соответствующий раздел. Они не имитируют фоновое
подтверждение серверной записи. Выход и смена сервера очищают снимок и инвалидируют контекст.

## Локальные уведомления

- Существующий opt-in в настройках; разрешение iOS не запрашивается при старте приложения.
- Напоминания за 30 минут для задач с настоящим временем и конкретных Google events.
  Задачи только с датой и события «весь день» не получают выдуманного времени.
- Формат как у календарных уведомлений: исходное название события/задачи в заголовке,
  фактическое время `22:45–23:45` под ним. Часы в 24-часовом формате часового пояса аккаунта;
  даты RU/EN добавляются при переходе через полночь или напоминании накануне, UTC offsets —
  при смене смещения в течение события. Время отправки и уровни прерывания не меняются.
- Календарь использует сохранённый пункт «Напоминания о задачах» в настройках уведомлений;
  переключатель окончания отдыха независим и сам календарные напоминания не включает.
- Горизонт локального планирования — 48 часов; расписание загружается с запасом и обновляется
  при открытии/возврате в приложение. Изменение события на сервере при закрытом приложении
  не может мгновенно отменить уже запланированное локальное уведомление. Серверный Telegram
  scheduler не меняется и продолжает работать независимо.
- Короткое уведомление об окончании отдыха. В открытой тренировке дублирующий баннер
  подавляется; при блокировке уведомление показывает iOS.
- Новая реальная покупка после импорта: короткие магазин/сумма. Тестовые покупки, дубликаты,
  пропущенные и подтверждённые строки уведомления не создают. File import сам по себе не
  запускает приложение в фоне; непосредственное сообщение транзакционной автоматизации
  по-прежнему показывает Shortcuts, как описано в существующих настройках Wallet.
- Namespace для аккаунта, покупок и отдыха разделены. Обновление задач не удаляет таймер
  отдыха. Поздний async add после отмены убирается; очистка не затрагивает чужие запросы.
- Контекст аккаунта сохраняется между процессами и меняется при выходе/401/смене сервера.
  Старая карточка аккаунта не открывает данные нового входа. Навигация после холодного
  запуска ждёт проверки сохранённой сессии. Уведомления не выполняют покупки или server CRUD.

## Проверка

Сборочные команды, ограничения xtool, metadata и проверка signed bundle описаны в
[`SYSTEM_FEATURES_BUILD.md`](SYSTEM_FEATURES_BUILD.md).

Регрессионные проверки находятся в `SystemSurfacesTests`, `LocalNotificationPlanTests`,
`LocalNotificationReconcilerTests` и `RestTimerCommandsTests`. Они проверяют расчёты,
таймзоны, нейтральные дни, переход упражнений, stale/replayed действия, холодный запуск,
атомарный cache round-trip, namespace cleanup и гонки add/cancel. Portable тесты и
unsigned сборка не заменяют установку и проверку новой сборки Ritm на iPhone.
